স্কুল অ্যাসাইনমেন্ট ডেমো

তোমার ব্রাউজার সম্পর্কে কী জানা যায়? 🔍

এই পেজটা দেখাবে তোমার browser ও device থেকে কী কী তথ্য স্বাভাবিকভাবে জানা যায় — একদম transparent ভাবে।
শর্তাবলী ও গোপনীয়তা

এটি শিক্ষামূলক browser-তথ্য ডেমো। কোনো তথ্য এই ডেমোর server/database-এ জমা হয় না; ফলাফল পেজে দেখানো হয়। তুমি “সম্মত” বললে browser/device তথ্য দেখানো হবে এবং public IP ও আনুমানিক অঞ্চল পেতে ipwho.is-এ অনুরোধ যাবে।

  • সাধারণ তথ্য: browser/OS-এর আনুমানিক পরিচয়, browser যে device model প্রকাশ করে, mobile/tablet/computer ধরন, screen ও viewport, ভাষা, timezone, স্থানীয় সময়, browser feature support, network-এর আনুমানিক ধরন/গতি, RAM/battery support, touch এবং online অবস্থা। browser কিছু তথ্য গোপন বা আনুমানিক করতে পারে; প্রকৃত device name/model অনেক সময় প্রকাশ করে না।
  • Camera/microphone: সম্মতির পর browser যে device-এর ধরন/নাম প্রকাশ করে তা পড়া হতে পারে। camera/mic চালু, permission চাওয়া বা recording করা হয় না।
  • GPS location: শুধু আলাদা location বোতাম চাপলে browser permission চাইবে; browser/device-এর location service-ও ব্যবহার হতে পারে। স্থানাঙ্ক ও accuracy পেজে দেখানো হবে; Google Maps link খুললে স্থানাঙ্ক Google-এ যাবে।
  • IP address: “সম্মত” চাপলেই public IP address ও আনুমানিক দেশ/অঞ্চল আনার জন্য তোমার browser সরাসরি ipwho.is-এ request পাঠাবে। ফলে provider তোমার IP পাবে; IP-ভিত্তিক অঞ্চল GPS নয় এবং ভুল হতে পারে। অসম্মত হলে এই request পাঠানো হবে না।
  • Browser তুলনা: snapshot সেভ করলে তা এই browser-এর local storage-এ থাকবে; JSON export/import করলে ফাইলটি তুমি নিজে স্থানান্তর করবে।
  • JSON: পেজের নিচে বর্তমান ফলাফলের JSON দেখানো হবে। এটি server-এ পাঠানো বা স্বয়ংক্রিয়ভাবে download করা হবে না।
  • অসম্মতি: অসম্মত হলেও অনুমতি বা বাইরের সেবা ছাড়া পাওয়া যায় এমন সাধারণ browser/device তথ্য দেখা যাবে। তখন location, IP lookup, media device list ও browser comparison চালু হবে না।

“সম্মত” চাপলে IP lookup স্বয়ংক্রিয়ভাবে হবে—এটি সম্মতির অংশ। GPS-এর জন্য আলাদা location বোতাম ও browser permission লাগবে। যেকোনো সময় পেজ বন্ধ করে বের হতে পারো।

তোমার তথ্য

এই তো তোমার browser যা জানালো 👀

ফলাফল এই পেজে দেখানো হয়। IP lookup বা Google Maps খুললে নির্বাচিত তথ্য সংশ্লিষ্ট provider-এর কাছে যেতে পারে।
Device ও Browser
Browser feature support
“সমর্থিত” মানে browser-এ API আছে; কোনো feature চালু/অনুমোদিত আছে—এটা সবসময় বোঝায় না। JavaScript না চললে এই পেজই খুলবে না।
নেটওয়ার্ক ও Device তথ্য
Network speed আনুমানিক। Browser/OS কিছু তথ্য সমর্থন না করলে বা গোপন রাখলে তা দেখা যাবে না।
Camera ও Microphone
শুধু device-এর নাম/সংখ্যা দেখা হয়। কোনো permission popup চাওয়া হয় না এবং recording করা হয় না। Browser নাম লুকিয়ে রাখলে এখানে তা জানানো হবে।
নেটওয়ার্ক / IP
IP থেকে পাওয়া অঞ্চল আনুমানিক; VPN, mobile network বা provider-এর database-এর কারণে ভুল হতে পারে। lookup করলে তোমার IP ipwho.is-এর সঙ্গে শেয়ার হবে।
লোকেশন
এখনো লোকেশন চাওয়া হয়নি।
Accuracy হলো আনুমানিক ব্যাসার্ধ (মিটার); এটি সবসময় GPS থেকে আসে না—Wi-Fi, mobile network বা device setting-এর ওপর নির্ভর করতে পারে।
Research: পদ্ধতি অনুযায়ী পাওয়া location

প্রতিটি পদ্ধতিতে এই পেজ বাস্তবে location পেয়েছে কি না নিচে দেখানো হয়। Device location পেলে browser কোন source (GPS/Wi-Fi/cellular) ব্যবহার করেছে তা সাধারণত জানায় না—তাই সেই source-গুলোর আলাদা ফলাফল অনুমান করে দেখানো হবে না।

পদ্ধতিএই পেজে পাওয়া location

Browser Geolocation API location দিলে সেটি device location service থেকে পাওয়া স্থানাঙ্ক; browser GPS/Wi-Fi/cellular-এর মধ্যে কোনটি ব্যবহার করেছে তা প্রকাশ করে না। IP location কেবল আনুমানিক অঞ্চল।

তথ্যসূত্র: W3C Geolocation API · MDN Geolocation API · MDN Web Bluetooth API

Browser-ভেদে তুলনা

প্রতিটি browser-এ পেজটি খুলে snapshot সেভ করো। অন্য browser-এর snapshot JSON হিসেবে export করে এখানে import করলে তুলনার টেবিল তৈরি হবে।

সীমিত তথ্য মোড

শর্তে সম্মতি দেওয়া হয়নি। তাই location, IP lookup, camera/microphone device list এবং browser-comparison storage ব্যবহার করা হয়নি.

বর্তমান ফলাফলের JSON

এটি এই পেজের বর্তমান ফলাফলের JSON preview। এখানে দেখানো ছাড়া কোথাও পাঠানো হচ্ছে না।
